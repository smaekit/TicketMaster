## Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | React, TypeScript, Tailwind CSS, React Router |
| Backend | Node.js, Express, TypeScript |
| Database | PostgreSQL |
| ORM | Prisma |
| Authentication | Database sessions (express-session) |
| AI | Claude API (Anthropic) |
| Email (Inbound) | Mailgun — webhook receives student emails and creates tickets |
| Email (Outbound) | SendGrid — sends AI-generated or agent replies to students |
| Deployment | Docker + cloud provider (AWS / Railway / Fly.io) |
